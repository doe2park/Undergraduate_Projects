# AnyLogic Models

This folder contains the AnyLogic simulation models developed during my undergraduate studies.  
The models focus on ground subsidence risk analysis, pipeline leakage modeling, and GIS-based agent simulations.

---

## Included Models

### **1. Hongik Evacuation Model**
A simulation model that analyzes evacuation performance in building layouts and congestion scenarios.

### **2. predictionmodelv1**
An early version of the subsidence prediction pipeline using:
- Pipeline age & diameter  
- Groundwater level  
- Street tree proximity  
- Soil layer information (USCS-based)  
- Subway line influence  

Includes probabilistic rupture triggers and spatial visualization.

### **3. Team C3 Final**
AnyLogic components used in the team’s capstone project, including:
- Risk factor integration  
- Spatial layout modeling  
- Scenario-based comparison
